BMED 2310 | DHF

Foley catheter design history file

Team 3, Foley's Fools, developed a design-history-file narrative for safer long-term indwelling catheter use after hospital discharge.

25Concept sketches from five ideation prompts
13 NRemoval-force threshold used for laceration-risk testing
3.2-12.3 NMeasured prototype removal/detachment range that stayed below threshold
  • Primary user group: men over 70 with urinary retention after discharge; the DHF cites about 10% prevalence over age 70 and about 33% by age 80.
  • Problem statement: reduce tissue lacerations from involuntary post-hospitalization Foley catheter removal.
  • Concept screening used a Benefit-Effort Matrix and Pugh Matrix; concepts included magnetic breakaway drainage tubing, an extendable tube, a foldable retention cushion, urethral ring balloons, and soft insertion petals.
  • Magnetic breakaway prototype: generation 0 detached at 3.2 N but disconnected too easily; generation 1 used a one-way valve and four magnets and detached at 6.9 N.
  • Foldable retention cushion: generation 0 removed at 8.3 N; later geometry refinement reached 12.3 N while remaining below the 13 N threshold.
  • Soft-petal insertion concept reduced glycerin carryover compared with baseline tests: less than 0.1 mL vs. 0.5 mL in one generation, and 0.2 mL vs. 0.6 mL in another.
Medical device risk | uFMEA

Fogarty catheter use-FMEA

A use-risk analysis translated instructions for use into task steps, failure modes, hazards, harms, current controls, and residual risk categories.

6IFU task steps: prepare, purge, inspect, place, inflate, withdraw
22Analyzed use-risk rows in the spreadsheet
9Unacceptable risks before added mitigation
  • Highest-severity hazards included intravascular air leading to air embolism, vessel perforation, dissection, rupture, and catheter separation.
  • Unacceptable purge risks included failure to remove air from the balloon lumen, using air instead of sterile fluid or CO2, and failure to purge the thru-lumen.
  • Placement and inflation risks included advancing against resistance, overinflating the balloon in the vessel, and continuing after balloon engagement with the vessel wall.
  • Withdrawal risks included excessive pull force, failure to adjust balloon diameter to changing arterial diameter, and pulling against adherent material.
  • Current controls included IFU warnings, sterile packaging, mandatory inspection, balloon-volume limits, heparinized saline purging, and contraindications for fibrotic, adherent, or calcified material.

Meaud Lab | MATLAB GUI

Cochlear micromechanics visualization tool

A MATLAB post-processing package for organ of Corti micromechanics that converts saved simulation frequency sweeps into interactive visual analysis.

5User inputs: file, x-location, frequency, observation angle, grid resolution
90 degRadial displacement projection convention
0 degTransverse displacement projection convention
  • Main API: computeOoCProjection(datafilename, xLocationCm, freqHz, observationAngleDeg).
  • The tool selects nearest saved xMesh location and frequency, computes complex 2D radial/transverse vectors, samples the 2D displacement field, and projects motion onto an observation angle.
  • GUI views include baseline/deformed OoC geometry, projected magnitude, projected phase relative to BM, landmark trajectories, saved structural frequency sweep, frequency sweep plots, displacement-vs-x plots, and point-response plots.
  • Implementation replaced hard-coded filenames, x-locations, inline plotting, and monolithic script structure with selectable files and modular folders for I/O, mechanics, geometry, plotting, validation, tests, and examples.
EPIC Lab VIP | Python + MATLAB

Motion-capture and sensor processing workflows

Research-tooling work for Vicon motion capture and insole sensor grids, linking raw experimental data to usable visual and numerical outputs.

31 x 11Fixed grid size used for each insole pressure map
5.0Binary threshold used before morphology operations
~24 hrREADME estimate for a full-subject Vicon processing run
  • Python pipeline parses headers like Insole1_sensel_x_y, maps values into two insole grids, and visualizes live sensor frames with fixed color scaling.
  • Feature operations include mean pressure, peak pressure, linear center of pressure, nonlinear center of pressure, binary thresholding, 2x2 morphological opening, active-sensor counts, and connected-component blob counts.
  • MATLAB AMP-with-GUI workflow targets MATLAB 2025a or later, Vicon Nexus, and a Windows workstation.
  • Vicon workflow includes static skeleton calibration, optional functional joint calibration, marker gap/jump checks, rigid-body recovery, failed-trial cleanup, and final movement of processed trials into finished folders.
BMED 3410 | Fusion simulation

Femoral bone compression simulation

A simplified cortical/trabecular femoral shaft model tested whether a cylindrical bone representation could approximate elastic response under a walking-scale compressive load.

2500 NApplied axial compression load
7.704 MPaMaximum von Mises stress
0.065 mmMaximum total displacement
  • Geometry: 120 mm-tall concentric cylinder with 30 mm outer cortical diameter and 18 mm inner trabecular diameter.
  • Material properties extracted from compression/torsion data: cortical Young's modulus 16.6 GPa, cortical shear modulus 6.39 GPa, cortical compressive yield strength 116.9 MPa.
  • Trabecular properties: Young's modulus 0.93 GPa, shear modulus 0.387 GPa, compressive yield strength 6.1 MPa.
  • Boundary conditions fixed the bottom surface and applied load normal to the top surface; minimum safety factor was 1.234.
  • Limitations explicitly identified population bias, osteoporotic underrepresentation, isotropic linear-elastic assumptions, simplified cylindrical geometry, and missing bending/torsion loading modes.
